# 🌐 PW III: ETEC Uirapuru

Atividades e projetos da disciplina **Programação Web III** (2026), do curso técnico em Desenvolvimento de Sistemas da ETEC Uirapuru.

| Atividade | Descrição | Tecnologias | Data |
|---|---|---|---|
| [`01-login-cadastro-crud`](01-login-cadastro-crud/) | Sistema de login e cadastro de usuários com CRUD completo | PHP, MySQL, PDO | 03/2026 |
| [`02-calculadora-e-pizzaria`](02-calculadora-e-pizzaria/) | Exercícios de formulários: calculadora e pedido de pizzaria | PHP | 08/2026 |
| [`03-catalogo-de-produtos`](03-catalogo-de-produtos/) | Catálogo de produtos com imagens vindas do banco de dados | PHP, MySQL, PDO | 08/2026 |

## Como rodar

Os projetos em PHP rodam no [XAMPP](https://www.apachefriends.org/): copie a pasta da atividade para `htdocs`, inicie o Apache e o MySQL, execute o script `.sql` da atividade no phpMyAdmin (quando houver) e acesse `http://localhost/<pasta>/`.
